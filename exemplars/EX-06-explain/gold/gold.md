# Gold answer

Compound interest is interest calculated on both the original principal and the interest already accumulated, so the balance grows by a percentage of an ever-larger base each period ("interest on interest"), producing exponential rather than linear growth. Formula: A = P(1 + r/n)^(nt), where P is principal, r the annual rate, n compounding periods per year, t years. Contrast: simple interest accrues only on the principal.
